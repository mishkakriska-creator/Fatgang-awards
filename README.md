# FatGang Awards 2026
Независимая русскоязычная музыкальная премия. 
- Live: https://fatgang-awards.onrender.com
- Admin: /admin.html (пароль в Render)
- GitHub main автоматически разворачивается в Render, Node.js, Frankfurt, free.
- Supabase PostgreSQL via session pooler. CA: certs/prod-ca-2021.crt. Не публиковать DATABASE_URL, ADMIN_PASSWORD или SESSION_SECRET.
## Файлы
public/index.html, style.css, app.js — интерфейс. public/logo.webp — предоставленный логотип (оптимизирован для веба). nominees.json — категории и номинанты; item: {id,name,image?,audio?}, медиа в public. server.js — Express API, PostgreSQL, сессии, bcrypt. render.yaml — конфигурация.
## Требования владельца
Пять категорий: артист, продюсер, обложка, трек, альбом года. До 3 разных номинантов за категорию, один необратимый бюллетень на аккаунт. 14 дней с VOTING_START (ISO дата/время). Не устанавливать до согласования. Регистрация только ник и пароль. Номинантов и медиа владелец передаёт для внесения в код. Админка только для результатов, не для изменения номинантов. Результаты не показывать публике до окончания. Дизайн: музыкальная премия в духе РЗТ, собственные цвета и оригинальный логотип FatGang.
## Текущий статус и задачи
Сайт запущен, категории пустые. Голосование закрыто. Сервер поддерживает регистрацию и голосование, админка базовая (JSON). До открытия голосования проверить безопасность базы: RLS/отключение Data API для внутренних таблиц включая session, ограничение частоты запросов, защиту от мультиаккаунтов, безопасную админку, смену ранее раскрытых секретов, тест регистрации/голосования. Добавить статистику по дням и процентам и результаты после окончания. Не менять сроки и реальные данные без согласования. Запуск локально: npm install, npm start с нужными переменными окружения. Не использовать production БД для тестов без разрешения.
